# Numeric tolerances for physics/orbit tests

Reference for every tolerance used across `src/core/**` tests — so a value can be looked up
and reasoned about in one place instead of re-derived at each call site. See
`CONTRIBUTING.md`'s "Testing orbital, RF, and simulation logic" for the
Independent-Reference-vs-Golden-Regression distinction these tolerances apply within.

| Check                                                                                              | Tolerance                                                    | Why                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| -------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GMST vs. independent Meeus formula (`docs/models/gmst.md`)                                         | `1e-6` rad (`toBeCloseTo(_, 6)`)                             | Both implementations evaluate the same IAU 1982 polynomial in float64; disagreement beyond float rounding (~1e-10) would indicate an implementation bug, not model error. `1e-6` leaves comfortable margin without being so loose it'd miss a real bug.                                                                                                                                                                                                                                                          |
| Sun elevation vs. independent Meeus solar position (`docs/models/sun-elevation.md`)                | `0.5°` (`toBeCloseTo(_, 0)`)                                 | `satellite.js`'s `sunPos()` (Vallado low-precision ephemeris) and the test's independent Meeus low-precision ephemeris are each individually accurate to ~0.01–0.02°; `0.5°` is a deliberately generous combined budget so the test isn't flaky from the two formulas' small structural differences (equation-of-center term count, nutation correction), while still catching a real bug (a wrong sign, a swapped lat/lon, a degrees/radians mixup) which would show up as an error of several degrees or more. |
| SGP4 position/velocity self-consistency (`sgp4.test.ts`, e.g. altitude/speed bands, orbit-closure) | Wide bands (tens of km / ~0.1 km/s) or **Golden Regression** | No independent SGP4 reference vectors are bundled yet (blocked on fetching Vallado's published `SGP4-VER.TLE`/`tcppver.out` test vectors — this sandbox can't reach an external source for them; see the open item in the plan). Existing tests check physically-reasonable bounds and internal consistency (does the orbit close on itself, is speed in the expected LEO range), which catches gross errors but is not a correctness proof. Treat as Golden Regression until real reference vectors are added.  |
| Imaging window edges (`imaging.test.ts`)                                                           | `5 s`                                                        | Self-generated at finer step resolution (1 s) than production code's search step (20 s + bisection); proves stability/regression, not correctness against an external tool. **Golden Regression.**                                                                                                                                                                                                                                                                                                               |
| Geometry self-consistency (`geodesy.test.ts`, `footprint.test.ts`)                                 | `1e-6`–`1e-9` (varies by assertion)                          | Closed-form spherical-trig identities checked against themselves (e.g. a circle's every point is equidistant from its center); tight tolerances are appropriate since these are exact analytic properties, not empirical measurements.                                                                                                                                                                                                                                                                           |

## Adding a new tolerance

When a new orbital/RF/simulation test needs a tolerance: state it explicitly (no bare magic
numbers), say in a comment or this table _why_ that value and not a tighter one, and record
whether the check is Independent Reference or Golden Regression per `CONTRIBUTING.md`.
